# 암호화와 키를 이용한 서버접속

오늘은 서버 상에서 데이타를 만들고, 그것을 각각 대칭키/비대칭키 암호화 방식으로 암호화하여 주고 받는 방식을 실습해볼것이다. 또한 비대칭키를 이용하여 유저네임과 패스워드 없이 다른 서버에 접속하는 방식도 알아보도록 하자.

오늘 가장 중요한 프로토콜은 SSH와 TLS(SSL)이다. SSH 기반의 SCP를 사용하여 파일을 암호화하여 송수신하고, TLS 프로토콜을 이용하여 키 인증 방식으로 웹페이지에 접근하는 방법을 확인해볼 것이다.

먼저, 두 서버간의 데이터  교환을 위해, 우분투와 로키를 사용하도록 한다.

암호화와 관련된 패키지는 GPG이다.

<aside>
💡

GPG : 데이터 암호화, 디지털 서명 생성&검증

실무에서는 주로 -c 옵션와 -d 옵션 사용

-c : 대칭키로 암호화

-d : 대칭키로 복호화

</aside>

암호문은 암호화되어 캣 명령어를 사용하더라도 읽을 수 없어진다.

이제 암호화된 파일을 SCP를 이용하여 우분투로 송신할것이다. SCP는 송신자의 명령으로 보낼 수도 있고, 수신자의 명령으로 가져올 수도 있다. 이번에는 우분투을 가동하여 수신자의 관점으로 가져와보도록 하겠다. SCP는 SSH 기반 도구이므로 SSH 모듈이 설치되어있어야 한다.

이번에는, 비대칭키 암호를 만들어볼것이다. 대칭키 방식과는 달리, 키를 파일로 만들어 저장해둬야 한다. 그래서 gpg처럼 바로 암호문을 만드는 것이 아닌, 먼저 키 쌍을 생성해줘야 한다.
