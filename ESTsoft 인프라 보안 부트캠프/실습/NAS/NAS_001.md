# NAS

오늘은 VMware에 NAS OS를 설치해서 서버로 운영해보겠다.

처음 설치는 보통의 리눅스 기반 OS와 동일하게 설치한다.

다만, VMware의 OS 구조에는 나스를 지원하지 않는 것 같으니, 이와 비슷한 FreeBSD 구조로 설치해준다.

<img width="428" height="430" alt="image" src="https://github.com/user-attachments/assets/08381d7d-bcfb-4df7-a2c2-31145d006d43" />


요 녀석은 자체 서버에서 작업을 많이 하지 않고, 주로 데이터 저장용으로 사용하기 때문에, 사양이 높을 필요가 없다. 메모리는 2기가, 초기 디스크(OS만 설치) 20기가로 설정했다.

<img width="720" height="860" alt="image" src="https://github.com/user-attachments/assets/d494d650-f9c8-44e1-b88a-0b5d388d2528" />


이렇게 설치가 완료된 모습이다.

NAS는 위에서도 언급했다시피, 하드 용량만 좋으면 되는 소규모의 공유 데이터 저장소로써의 역할을 톡톡히 한다. 이를 위해 보통은 하나의 장치(여기서는 머신)에 여러 개의 하드를 꽂아서 사용한다. 그렇기에 우리도, 몇몇의 하드를 더 추가해주겠다.

<img width="444" height="430" alt="image" src="https://github.com/user-attachments/assets/6b18cdfd-7f14-43e3-92af-db01c4bb4ea0" />


버츄얼 머신 셋팅의 [add] 버튼을 눌러 하드 디스크를 3개 가량 추가한다.

<img width="759" height="734" alt="image" src="https://github.com/user-attachments/assets/4160be4d-f201-49a3-bccb-423610d275e1" />


이렇게 3개의 하드 추가를 완료했다. 설치를 시작해보자.

<img width="724" height="532" alt="image" src="https://github.com/user-attachments/assets/3ccffe13-3a2f-4324-ab64-a866485443ea" />


특별히 신경쓸만한 부분은 없었다.

설치가 완료되었으니, DVD에 넣었던 설치 프로그램은 제거하고, 재부팅한다.

<img width="693" height="514" alt="image" src="https://github.com/user-attachments/assets/a734f22d-9959-4783-900e-3eb3c0771147" />


셋업 화면이다. NAS의 용도 자체가 로컬 네트워크 저장소이기 때문에, 네트워크 세팅은 필수적이다. 일단은 1번을 눌러보자.

<img width="724" height="514" alt="image" src="https://github.com/user-attachments/assets/11ac616b-0029-4830-9720-cc8706c7566b" />


1번을 누르고 차례로 세팅한다. 서버이기에 내가 IP를 직접 할당한다.

<img width="724" height="514" alt="image" src="https://github.com/user-attachments/assets/e98cf691-67f2-4fec-a78b-a4b9fd98b3a3" />


세팅이 모두 완료되었다. 이제는 이 NAS 서버를 공유 저장소로 만들어야 한다. 물론 CLI 환경에서 설정할 수도 있지만, 오늘은 GUI 환경으로 설정을 진행해보겠다.

**여기에서 필요한 것이 NAS보다 성능이 좋은 호스트(머신)이다. NAS와 같은 CLI OS 중 다수는 GUI를 위한 웹서버(관리용으로 만들어짐)를 백그라운드로 항상 실행하고 있다. 단지 서버 호스트의 성능이 낮기에, CLI로만 보이고 있는것이다. 하지만 이러한 서버를 성능이 좋은 머신에서 원격으로 실행한다면, GUI 환경으로 설정할 수 있게 된다.**

자, 이를 위해 성능이 좋은 우분투의 터미널을 실행하자.

스토리지를 확인해보면, 예쁘게 잘 만들어진 모습이다. 이제 이러한 서비스를 시작해야 한다.

일단 처음으로 해줘야 하는 건 NFS를 설치하는 것이다. 다른 서버에 있는 디렉터리를 마운트하기 위한 기능이다.

<img width="361" height="49" alt="image" src="https://github.com/user-attachments/assets/092cb589-abb2-4d6d-9e70-c7c620422a87" />

NAS에 디렉터리가 마운트되면, 해당 디렉터리의 파일과 폴더는 언마운트 될 때 까지 숨김처리된다. 언마운트 후에 다시 돌아온다. 또한 마운트 중에 업로드한 모든 자료는 나스서버에 저장되므로, 언마운트시 마운트했던 디렉터리에서 사라지게 된다.

</aside>

와… 정말 재밌는 실습이었다. 하드 용량을 제외한 모든 것들이 가치가 없는 컴퓨터일지라도 데이터 저장소로서의 역할을 톡톡히 해내는, 너무도 효율적이고 실용적인 서비스였다. 실제 내가 취업을 하게 되어도 이 기술은 분명히 사용 가능할 것 같다. 이론으로만 알았던 것들을 직접 손으로 설정해보면서 되게 재미있었다.
