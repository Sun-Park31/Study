# 정보보안 일반

sub: 3
상태: 시작 전

- 접근통제방식
    - DAC : 임의적 접근통제
        - 사용자나 그룹의 신원에 따라 접근 통제
    - MAC : 강제적 접근통제
        - 사용자 자체에 부여된 인가와 자원에 부여된 보안 수준 비교에 따라 접근 통제
    - RBAC : 역할기반 접근통제
        - 역할과 역할이 가진 자원 기반 접근통제
    - 쇼단 : 인터넷에 연결된 기기의 다양한 정보 제공 검색엔진
    - 웹의 종류
        - 표층 웹 : 일반적 웹 브라우저
        - 딥 웹 : 비공개 인터넷 영역, 개인 메일, 회사 내부망 등 해당
        - 다크 웹 : 딥 웹의 일종. 특수 브라우저를 통해서만 접근 가능
- 익명 네트워크를 이용한 사이버 공격
    - 토르 : 다크웹 접속 소프트웨어로 주로 사용(사용자와 서버 사이에 중간 노드로 추적 혼선)
    - 가상 사설망(VPN) : 출발지 IP 숨겨 공격
    - 프록시 : 서버와 사용자 사이에 프록시 서버로 중간교환기 해줌 → 추적 어려움
