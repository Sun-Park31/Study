# 네트워크 보안

상태: 시작 전

- 통신 프로토콜 관련 공격
    - DoS : 네트워크 대역 고갈
        - TCP SYN Flooding
        - HTTP GET Flooding, HTTP CC
    - 스니핑 : 랜카드 무차별 모드 설정, 모든 IP패킷 훔쳐보기 >랜카드 Promiscuous 모드 설정
        - 스위치 재밍(MAC 플러딩) : ARP 요청 많이 해서 스위치 브로드 뿌리게 만들기
        - SPAN 포트 태핑
    - 스누핑 : 몰래 정보 획득
    - 스푸핑 : 포트번호, IP, MAC 조작
        - ARP 스푸핑 : IP에 대한 MAC값 속이기
        - IP 스푸핑 : 도스로 클라이언트 죽이고 클라이언트 IP로 클라이언트인 척 서버접속
            
            >> 세션 하이재킹도 함께 하는 경우 흔함
            
        - DNS 스푸핑
    - 세션 하이재킹 : 정상 로그인 사용자의 세션 탈취

        - HTTP 세션 하이재킹 : HTTP 세션 ID 탈취하여 세션 탈취
    - Dos 공격
        - 랜드어택 : 출발지 주소와 도착지 주소 동일
        - 스머프 어택 : 출발지 주소를 도착지 주소로 변조
            
            라우터에서 다이렉트 브로드캐스트 패킷 필터링으로 막아야 함
            
            IP 브로드캐스트 어드레스로 전송된 ICMP Echo Request 미응답 설정으로 막아야 함
            
        - Ping of Death : 엄청 큰 ICMP 패킷 보내서 시스템 마비
        - TCP SYN Flooding 어택 : SYN 희생자에 다수 전달. TCP 하프오픈으로 공격, SNY+ACK에 정상연결이라면 ACK나 RST를 보내야 하지만, 아무것도 안 보내서 하프오픈 상태 유지로 자원 소모
        - Slow HTTP Header DoS 공격 : HTTP 요청시 헤더 끝 의미하는 개행문자 안 보내고 불필요한 헤더만 천천히 계속 보냄
        - Slow HTTP Post DoS 공격 : HTTP POST 하면 헤더 중간랭스 늘려서 강제로 연결자원 소모
        - Slow HTTP Read DoS 공격 : TCP 제로 윈도우 보내서 연결자원 소모
        - DNS 증폭 공격 : DNS Record 질의타입을 ANY로 지정
            
            ANY : DNS 관련 정보 다 줘
            
            TXT : DNS 관련 정보 중에 TXT 만 줘
            
            - DNS 증폭 DRDos 공격 : TXT 질의에 대한 응답 단편화로 송신 데이터 많아져 서버 마비
        - 멤캐시드 : 메모리 캐싱 시스템, 보안설정 안 되어 있어서 희생자 ip 가지고 특정 명령 송신 → 멤캐스드에서 희생자에게 응답 매우 많이
        - WDS : 자동 장비 검색 기술, 희생자 ip 가지고 XML 오류 응답 나오게 함
        - ARMS : IP 위조하여 취약 애플Mac 원격접속 요청 → 증폭응답
        - CoAP : IoT 저전력 기기를 위한 프로토콜, IP 스푸핑 해서 GET Request 보내 응답 폭주
    - 알려진 DDos 공격
        - Trinoo, TFN, Stacheldracht, TFN2K, Shatt, Mstream, Trinity
        - 봇넷 : 좀비PC의 집합체, 주로 DDoS 공격에 사용
            - 중앙 집중형 명령/제어 방식 : IRC 봇넷, HTTP 봇넷
            - 분산형 명령/제어 방식 : P2P 봇넷

            - 봇들의 방화벽 우회 기법 : C&C 서버 접속시 방화벽 탐지 우회
                - Fast Flux : IP 여러개로 TTL 짧게 해서 계속 접속 → 누군가는 들어간다.
                - DGA : 임시 도메인명  지속적 동적 생성으로 우회
                - Domain Shadowing : 공인 도메인 아래에 서브도메인 몰래 끼워넣기로 인증
        - HTTP GET Flooding : 좀비PC 시켜서 HTTP GET 요청 지속(정상적 방법 공격)
    - hping3 : 네트워크 보안장비 테스트(DDoS 공격 모의훈련 등)

        - 포트 미러링(SPAN) : 포트로 가는 것이나 VLAN의 패킷 다른 모니터링 포트로 복제
        - VLAN : 스위치에서 서브넷 나눠서 랜 여러개로(브로드캐스트 효율 업) 보안 강화, 성능 향상
            - Port 기반 VLAN : 포트 구멍 몇 개씩 나눠서
            - MAC 기반 VLAN : 자리를 어디로 옯겨도 항상 같은 VLAN에 들어가게
            - 네트워크 주소 기반 VLAN : 서브넷 기반(네트워크 주소 기반)
            - 프로토콜 기반 VLAN : 네트워크 계층 프로토콜 종류에 따라
            - 정적 VLAN : 관리자가 직접 스위치 모든 포트에 VLAN 설정
            - 동적 VLAN : 장비나 프로그램을 이용하여 자동 VLAN 설정(보통 MAC 주소 기준)

            - tcpdump : IP 패킷의 단편화(쪼개전송) 파일

            - MTU : 네트워크의 최대 전송 가능 용량
                
                단편화시 MTU로 나누고, 첫 단편에서 20 바이트를 제외하고 전송
                
            - 패킷 단편화 관련 공격
                - Fragment Overlap 공격 : 공격패킷 첫 단편은 HTTP(80)로 자유통과, 재조합시 2번 단편이 1번 단편 일부 수정 가능하게 offset 조작
                - Tiny Fragment 공격 : 헤더가 쪼개질 정도로 작게 단편화 → 패킷 필터링 1번 통과하므로 순차 다 통과
                - TearDrop 공격 : 단편화 사이 중복값 발생으로 offset 겹쳐 OS 오류 및 블루스크린

        - 제어비트
            - URG : 긴급 데이터 전송 알림
            - ACK : 상대에게 ㅇㅇ 전송
            - PSH : 송수신 버퍼 데이터의 즉시 처리 요청
            - RST : 연결 강제 중단 요청
            - SYN : 연결 설정 요청
            - FIN : 연결 정상 종료 요청
        - 비정상 연결 종료시 TCP keepalive로 응답 없을 시 연결 종료.
        - 포트 스캐닝 : 어떤 포트 열려있는지 확인
            - 연결형 스캔
                - TCP Connect 스캔 : 정상 스캔
                    - 열린 포트 : SYN → SYN+ACK → ACK → RST
                    - 닫힌 포트 : SYN → RST+ACK
            - 스텔스 스캔 : 포트 열려있으면 미응답/ 포트 닫혀있으면 RST+ACK
                - TCP SYN 스캔(반 개방형 스캔)
                    - 열린 포트 : SYN → SYN+ACK → RST
                    - 닫힌 포트 : SYN → RST+ACK
                - TCP FIN 스캔
                    - 열린 포트 : FIN → 미응답
                    - 닫힌 포트 : FIN → RST+ACK
                - TCP NULL 스캔
                    - 열린 포트 : 무지 → 미응답
                    - 닫힌 포트 : 무지 → RST+ACK
                - TCP Xmas 스캔
                    - 열린 포트 : FIN, URG, PSH → 미응답
                    - 닫힌 포트 : FIN, URG, PSH → RST+ACK

- 무선랜
    - 무선랜 보안 표준/보안규격
        - WEP = IEEE 802.11
            - RC4 방식 사용 : 24비트 IV 사용해서 RC4 스트림 암호화 방식으로 보호
                
                공유 비밀키와 IV 값 평문으로 보내 취약점 존재(대칭키 방식)
                
        - WPA = IEEE 802.11i
            - WEP과 동일한 RC4 방식,  48비트 IV 사용하는 RC4-TKIP 암호화 방식
        - WPA2 = IEEE 802.11i
            - WPA와 키관리 유사성, AES기반 128비트 대칭키, AES-CCMP 암호화 방식
        - WPA3
    - SSID : 무선랜을 구분하기 위한 이름
        - 관리자 모드시 비밀번호, 케이스 등으로 물리 보호, SSID 변경하여 초기값과 다르게, SSID는 브로드캐스트 하지 않고 숨김, 안전 암호화 방식 선택, MAC 필터링
    - 워드라이빙 : 무선 장치 가지고 주위의 AP를 찾는 과정
    - VPN : 가상사설망
        - 외부에서 전용망 뚫어 원하는 곳과 연결
        - 2계층 프로토콜
            - PPTP (MS) : 포인트 투 포인트 터널 : 하나의 터널에 하나의 연결만
            - L2F(CISCO) : 하나의 터널에 여러 개의 연결
            - L2TP(MS+CISCO) : L2F 기반, PPTP와의 호환성 고려
        - 3계층 터널링 프로토콜
            - IPsec : 3계층 동작 표준화 터널링 프로토콜, IP 패킷에 대해 다양한 보안
                
                기밀성, 비연결형 무결성, 데이터 원천 인증, 재전송 공격 방지(이를 위해 순서번호 사용), 접근제어, 제한적 트래픽 흐름의 기밀성
                
                - AH 프로토콜 : 인증 + 무결성
                - ESP 프로토콜 : AH + 기밀성
                
                키교환은 IKE 알고리즘 이용
                
                - 동작 모드
                    - 전송 모드 : IP 헤더 제외한 IP 패킷 페이로드 보호 모드
                    - 터널 모드 : IP 패킷 전체 보호 모드

    - 세부 프로토콜
        - Handshake : 종단 호스트 간 보안 협상
            
            보안 협상 > 서버 인증 및 키교환 > 클라이언트 인증 및 키 교환 > 메시지 교환
            
        - Change Cipher Spec : 협상한 보안 변경, 적용
        - Alert : 오류발생 통보
        - Application Data : 응용계층 데이터 전달
        - Record : 메시지 인증 코드 생성, 암호화 및 복호화, (표현계층 느낌)
            - 단편화 > 압축 > MAC 생성 > 암호화
    - DTLS 프로토콜 : TLS 기반, UDP에 보안 제공
    - WTLS 프로토콜 : 무선환경 TLS
    - TLS 1.3은 과정 함축된 1-RTT, 0-RTT 지원
    - 취약성 공격
        - BEAST attack : 브라우저 취약점으로 HTTPs 쿠키 훔쳐 세션 탈취
        - CRIME attack : HTTPs 압축 취약점으로 HTTPs 쿠키 훔쳐 세션 탈취
- SSH 22포트: FTP, Telnet, rlogin, rsh 스니핑 막기 위한 보안 통신 서비스
    - 파일 보안 트랜스퍼 위해 존재
- 라우터 보안 기능
    - Ingress 필터링 : 들어오는 IP 허용거부
    - Egress 필터링 : 나가는 IP 허용거부
    - 블랙홀 필터링 : 목적지 IP Null인 곳으로 보내버리기
    - access-list 100 deny udp any any eq udp
    - Cisco IOS
        - no snmp로 snmp 비활성화
        - no IP directed-broadcast로 다이렉트 브로드캐스트 비활성화
    - 정적/동적 라우팅
        - 정적 라우팅 : 관리자가 직접 라우팅 테이블 설치
        - 동적 라우팅 : 라우팅 프로토콜 이용하여 자동 경로 탐색
            - IGP : 자율 시스템 내부 라우팅
                - 거리 벡터 방식 : RIP, RIPv2, IGRP
                - 링크 상태 방식 : IS-IS, OSFP
                - 하이브리드 방식 : EIGRP
            - EGP : 자율 시스템 간 라우팅
                - 경로 벡터 방식 : BGF
